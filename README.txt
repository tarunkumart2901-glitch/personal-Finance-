LEDGER — PERSONAL EXPENSE TRACKER

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Add income and expense records. Data is saved in this browser using localStorage.

Features:
- Responsive dashboard with balance, income and expense summaries
- Add and delete transactions
- Search plus category and type filters
- Export all records to CSV
- INR formatting and local date handling
- Accessible labels, keyboard focus, and status announcements

Notes:
- Data stays in this browser/device; clearing browser data can remove it.
- This is a front-end demo, not a secured multi-user financial application.
- Google Fonts load from the internet; system fonts are used if unavailable.
